# 병원 소개

- `page.tsx`는 서버 컴포넌트다. 의료진·직원·병원·진료시간 정보는 `lib/constants.ts`의 실제 사용 상수를 확인한다.
- 시설 사진은 `public/images/facility/`, 시설·장비 설명과 배치는 페이지에서 관리한다.
- 의료진 정보 변경 시 화면뿐 아니라 metadata와 의사·breadcrumb JSON-LD도 확인한다.
- KakaoMap은 소개·연락처 등에서 공유한다. 지도 변경은 한 페이지 전용이라고 가정하지 않는다.
- 사진 교체 시 비율·sizes·alt와 모바일 배치를 확인한다. 의료진 사진·자격·장비 정보를 임의로 추가하지 않는다.
