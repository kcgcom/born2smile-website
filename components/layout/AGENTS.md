# 전역 레이아웃 UI

- `Header.tsx`는 클라이언트 내비게이션이다. 모바일 메뉴의 Escape·포커스 트랩·스크롤 잠금·닫기 이벤트를 보존한다.
- `mobileMenuEvents.ts`는 메뉴 닫기 이벤트를 공유한다. FloatingCTA와 Header 사이의 동작을 따로 변경하지 않는다.
- `Footer.tsx`는 async 서버 컴포넌트로 운영 병원정보·진료시간·링크를 조회한다. Header의 코드 상수와 같은 데이터 경로라고 가정하지 않는다.
- `FloatingCTA.tsx`의 모바일 빠른 메뉴와 데스크톱 CTA를 구분한다. 화면 하단 여백·본문 가림·안전 영역을 확인한다.
- 플로팅 진료 상태는 루트 레이아웃에서 받은 운영 진료시간과 날짜별 예외를 사용한다. `lib/clinic-hours.ts`의 시간 해석은 JSON-LD와 공유한다.
- 전화·지도·SNS 링크의 추적 이벤트와 접근성 이름을 유지한다.
- 헤더 반응형 기준을 바꾸면 CSS·메뉴 표시·관련 tests의 기준이 일치하는지 확인한다.
