# 카테고리 허브 운영 가이드

이 디렉터리는 공개 `/blog/[category]` 페이지의 큐레이션 설정 코드다. 타입은 [shared.ts](shared.ts), 집계·검증은 [index.ts](index.ts), 실제 표시는 [허브 페이지](../../../app/blog/[category]/page.tsx)가 담당한다.

## 현재 설정 구조

| 필드 | 역할 |
|---|---|
| `heroTitle`, `heroDescription` | 허브 소개 |
| `audience` | 주로 읽을 독자·상황 |
| `questions` | question·answer·slug로 구성한 질문과 연결 글 |
| `sections` | title·description·slugs로 구성한 읽기 묶음 |

질문은 3~4개, 섹션은 3개 안팎을 출발점으로 삼되 고정 개수로 강제하지 않는다. 질문에는 짧은 답을 함께 쓰고 섹션은 환자의 상황·단계에 따라 나눈다.

## 글 연결과 공개 여부

- 같은 카테고리의 실제 slug만 사용한다. `index.ts`는 생성된 BLOG_POSTS_META에서 존재 여부와 카테고리 일치를 검사하고 불일치 시 오류를 낸다.
- 메타데이터 존재만으로 발행 여부가 보장되지는 않는다. 페이지는 공개 조회에서 받은 categoryPosts와 다시 연결하며 초안·예약 글은 공개 조건에 따라 제외된다.
- 글을 삭제하거나 카테고리를 옮기면 기존 허브의 질문·섹션 연결도 확인한다.
- 모든 글을 나열하기보다 대표 질문과 읽기 순서를 안내한다. 의료 설명의 작성·출처 기준은 [작성 가이드](../../../docs/blog-writing-guide.md)를 따른다.

## 수정·검증

해당 카테고리 파일을 수정하고 데이터가 필요한 경우 스냅샷 → 메타데이터 순서로 갱신한다. 생성 파일은 직접 편집하지 않는다. 타입 검사·린트·빌드 및 관련 UI 검증은 [루트 지침](../../../AGENTS.md#검증)을 따른다. 배포는 검증과 별도 승인 범위다.
