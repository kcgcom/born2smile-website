# docs/

- 현재 동작은 실제 코드·설정·마이그레이션과 대조한다. 설계안·평가 결과는 작성 시점과 구현 여부를 명시하고 운영 보장처럼 표현하지 않는다.
- 공통 작업·검증·배포 규칙은 루트 `AGENTS.md`가 단일 소스다. `CLAUDE.md`에 같은 규칙을 복제하지 않는다.
- 사용자용 시작 안내는 `README.md`, 작성 기준은 `blog-writing-guide.md`, 발행 절차는 `blog-workflow.md`에 둔다.
- 환경변수는 `environment-variables.md`와 `.env.example`·실제 사용처를 대조한다. 값은 공개하지 않는다.
- 데이터 흐름은 `supabase-architecture.md`, 출처는 `source-link-policy.md`, 점수·평가는 해당 도메인 문서를 유지한다.
- 파일 목록·버전·TTL·항목 수를 불필요하게 복제하지 않는다. 바뀌기 쉬운 값은 구현 위치를 안내한다.
- 삭제할 문서는 링크·도구 참조·고유한 운영 지식이 없는지 확인한다. 오래된 기록은 용도가 남아 있으면 역사적 기록으로 표시한다.
- Markdown 경로·링크·명령을 검증하고, 문서만 변경한 경우 앱 빌드는 실행하지 않는다.
