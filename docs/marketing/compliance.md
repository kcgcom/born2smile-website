# 마케팅 준수 정책

- 공개 전 담당 의료인이 의료광고 해당 여부와 매체별 심의 요건을 확인한다. 허위·과장, 치료 효과 보장, 오인 우려가 있는 치료경험담, 타 의료기관 비교·비방, 중요한 부작용 누락, 허위 긴급성이나 부당한 환자 유인 표현을 사용하지 않는다. 의료 콘텐츠의 발행·예약을 자동화하지 않는다. [의료법 제56·57조](https://www.law.go.kr/법령/의료법) · [치과 의료광고심의위원회](https://www.dentalad.or.kr/main/)
- 환자 식별정보, 상담 원문·녹취, 진료기록, 개인별 건강 추론과 원시 방문자 ID를 외부 도구에 전송하거나 보고서에 포함하지 않는다. 공개 리뷰도 식별 가능한 인용 대신 집계나 비식별 요약을 사용한다. [개인정보 보호법 제23조](https://www.law.go.kr/법령/개인정보보호법)
- 유료이거나 과금 여부가 불명확한 호출은 비용과 범위를 확인하고 사용자 승인을 받은 뒤 수행한다. 키 보유는 과금 승인이 아니다. 제공된 자료와 권한이 있는 비과금 읽기 전용 조회에는 별도 승인을 요구하지 않는다.
- 운영 DB·추적 설정 변경, 외부 전송, 광고 집행, 실제 문의·예약은 사용자가 허용한 범위에서만 수행한다.
