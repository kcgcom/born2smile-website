# 지역 검색

- Google·네이버의 지도 및 검색 결과와 공식 웹사이트를 각각 확인한다. 병원명·주소·전화·진료시간·공식 URL의 기준 정보를 정하고 플랫폼·URL별로 불일치, 조회일, 확인 가능한 수정 주체를 기록한다.
- 지역별 검색 결과는 검색어, 위치·기기와 시점에 따라 달라진다. 노출과 홈페이지 이동, 전화 링크 클릭을 각각 기록하고 실제 통화·예약은 별도의 검증 자료가 있을 때만 보고한다.
- 수정 제안은 잘못된 방문 정보와 연락처부터 우선한다. 허위 리뷰, 리뷰 보상, 지역 키워드만 바꾼 유사 페이지 양산을 제안하지 않는다.
