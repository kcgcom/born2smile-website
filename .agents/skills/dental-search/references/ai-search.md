# AI 검색

1. 대표 환자 질문과 재현 조건을 고정한다. 질문, 날짜·시각, 서비스·모델, 검색 사용 여부, 인용 URL을 기록한다. 실제 관찰과 합성 예시는 구분한다.
2. 답변에서 검증 가능한 주장마다 현재 공식 안내, 인용 페이지가 뒷받침하는 내용, 판정과 환자에게 미칠 영향을 적는다. 병원 운영 정보는 현재 공식 운영 안내를, 임상 주장은 적용 범위에 맞는 임상 원문을 기준으로 삼는다.
3. 공식 원문 오류, 외부 출처의 오래된 정보, 인용 내용과 답변의 불일치, 색인·렌더링 문제를 구분해 출처별 수정 제안을 낸다. 검색용·학습용 크롤러 정책은 구분하고 변경은 승인된 흐름을 따른다.
4. 출처 수정이 확인되면 같은 조건에서 다시 질의해 주장과 인용을 대조한다. 결과가 달라질 수 있으므로 필요하면 반복 횟수와 관찰 기간을 명시한다. 정정 여부, 인용 빈도, 노출을 각각 기록하고 llms.txt를 필수 순위 요인으로 단정하지 않는다.
