# 접근성 감사

WCAG 2.1 AA를 기본으로 하며 기준 원문은 https://www.w3.org/TR/WCAG21/ 를 참조한다.
- 제목 계층, landmark, 목록, 네이티브 버튼·링크 의미를 확인한다.
- 접근 가능한 이름, aria-expanded/controls/describedby, role 오용, 폼 레이블 및 오류·저장 상태 안내를 확인한다.
- 키보드 순서, skip link, focus-visible, 모달 포커스 트랩·복귀, Escape, 스크롤 잠금 해제를 확인한다.
- 의미 있는 이미지의 alt, 장식 이미지의 빈 alt, 확대·리플로우, reduced-motion을 점검한다.
- 일반 텍스트 대비 4.5:1, 대형 텍스트(18pt 일반 또는 14pt 굵게, 약 24px 또는 18.67px) 3:1, 해당 비텍스트 UI 요소 3:1을 기준으로 예외와 실제 배경을 확인한다.
- sRGB 채널 c를 0~1로 정규화한 뒤 c <= 0.04045이면 c/12.92, 아니면 ((c+0.055)/1.055)^2.4. 상대 휘도 L=0.2126R+0.7152G+0.0722B, 대비=(밝은 L+0.05)/(어두운 L+0.05). 투명도·배경 합성을 고려한다.
- DESIGN.md의 44px 수준 터치 목표는 프로젝트 기준으로 별도 평가한다.
- Header/Footer, FAQ, 목차, 질문 해결 피드백, 연락처·지도, 관리자 폼을 범위에 맞춰 확인한다.
- 코드만으로 스크린리더 호환성이나 WCAG 전체 준수를 보장하지 않는다. 실제 검증 범위와 기준 번호를 기록한다.
