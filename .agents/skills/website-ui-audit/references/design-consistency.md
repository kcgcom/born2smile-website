# 디자인 일관성 감사

- DESIGN.md의 공개 사이트 방향, app/globals.css의 실제 @theme inline 토큰, lib/fonts.ts의 폰트 설정을 대조한다. 관리자 화면은 기존 관리자 컴포넌트 기준을 사용한다.
- 색상·간격·폰트 토큰을 필요한 범위에서 확인하고 rg 등으로 임의값, RGB/HSL, inline style을 탐색한다.
- 임의값 자체를 결함으로 단정하지 않는다. CSS 변수 참조, 데이터 시각화, 외부 위젯, 의도된 예외를 구분한다.
- 브랜드 색상, 버튼·링크·활성 상태, 타이포그래피 역할, section-padding/container-narrow 및 공통 컴포넌트 재사용을 점검한다.
- 실제 렌더링과 코드 근거를 함께 확인하고 대체 토큰 또는 패턴을 제안한다. 토큰 목록과 값은 이 문서에 복제하지 않는다.
