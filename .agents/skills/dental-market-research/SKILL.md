# dental-market-research

루트 및 대상 AGENTS.md를 따른다. 실행 전 [준수 정책](../../../docs/marketing/compliance.md)과 [공통 컨텍스트](../../../docs/marketing/context.md)를 이 순서로 확인한다. 기존 자료로 답할 수 없는 중요한 사항만 질문한다.

지역·비교 대상·조사일·공개 자료 범위를 정한다. 공식 홈페이지와 공개 검색 결과에서 관찰된 진료 안내, 정보 구조, 주제 및 접근 편의성을 비교한다. 관찰 사실, 추론, 시사점을 분리하고 미관찰을 부재로 단정하지 않는다. 유료 트래픽 추정 도구를 사용하지 않으며 확인 불가 지표는 누락 표시한다. 경쟁 기관의 치료 품질·환자 수·매출을 추정하지 않는다. 결과는 내부 개선 기회로만 사용하며 비교·비방 광고를 만들지 않는다.

- 같은 관찰 조건과 기준으로 기관별 비교표를 만든다. 각 행에 항목, 알려진 관찰 URL·기준일, 실제 확인한 메뉴 단계 또는 문구의 비식별 요약, 확인 여부를 적는다. 입력 자료에 없는 날짜는 미제공, 직접 열지 않은 원문의 조회일은 미확인으로 표시한다.
- 비교에서 발견한 차이는 서울본치과에서 검증 가능한 내부 개선 가설로 바꾼다. 증거가 적으면 조사할 항목과 한계를 남기고 순위표나 공개 광고로 변환하지 않는다.
- 경쟁 사이트의 동선 비교와 서울본치과 개선 가설 도출은 이 스킬에서 처리한다. 서울본치과의 실제 문의 경로를 별도로 진단하는 요청에 dental-patient-experience를 적용한다.

결과는 [리서치 계약](../../../docs/marketing/research-contract.md)에 맞춰 근거·한계·승인 필요 여부를 기록한다.
