# dental-marketing-review

루트 및 대상 AGENTS.md를 따른다. 먼저 [공통 컨텍스트](../../../docs/marketing/context.md)와 [준수 정책](../../../docs/marketing/compliance.md)을 읽는다. 기존 자료로 답할 수 없는 중요한 사항만 질문한다.

기간과 목적을 정하고 필요한 하위 스킬만 선택한다. 기존 보고서와 비교하여 성과 변화, 콘텐츠 최신성, 검색·환자 수요 및 개선 기회를 평가한다. 반복 작업은 주기, 실행 조건, 검증, 중복 키, 상태, 중단 조건, 승인 지점, 비용 범위를 정의한다. research-contract.md 형식으로 보고한다. 현재는 수동 검토만 수행하며 스케줄 생성·자동 발행·광고 집행·DB 변경을 하지 않는다.

결과는 [리서치 계약](../../../docs/marketing/research-contract.md)에 맞춰 근거·한계·승인 필요 여부를 기록한다.
