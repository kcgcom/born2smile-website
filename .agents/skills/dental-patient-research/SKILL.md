# dental-patient-research

루트 및 대상 AGENTS.md를 따른다. 실행 전 [준수 정책](../../../docs/marketing/compliance.md)과 [공통 컨텍스트](../../../docs/marketing/context.md)를 이 순서로 확인한다. 기존 자료로 답할 수 없는 중요한 사항만 질문한다.

조사 질문·기간·플랫폼을 정하고 국내 공개 검색, 지식iN, 공개 커뮤니티와 기존 비식별 집계를 우선한다. 중복 게시물과 광고성 자료를 구분한다. 질문·불편·오해·정보 부족으로 분류하고 독립 자료 수, 반복성, 반례, 표본 편향을 기록한다. 개인별 프로필·리뷰 원문·녹취는 수집하지 않는다. 의견을 임상 사실로 취급하지 않고 공식 근거로 별도 검증한다. 인터뷰 모집·보상·환자 접촉은 기본 범위 밖이다.

- 자료별로 질문 주제, 기간, 채널, 독립 관찰 건수와 중복·홍보성 제외 기준을 남긴다. 중복 포함 여부를 모르면 계산의 가정이나 가능한 범위를 표시한다. 채널 여러 곳에서 반복된 신호와 단일 출처 관찰을 구분한다.
- 근거가 약한 주제는 가설로 남기고, 공개 표본을 전체 환자 수요로 일반화하지 않는다. 소수 집단은 비식별 요약에서도 조합으로 식별 가능한지를 점검하고 필요하면 범주를 합치거나 생략한다.

결과는 [리서치 계약](../../../docs/marketing/research-contract.md)에 맞춰 근거·한계·승인 필요 여부를 기록한다.
