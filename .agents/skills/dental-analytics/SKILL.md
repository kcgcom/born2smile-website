# dental-analytics

루트 및 대상 AGENTS.md를 따른다. 실행 전 [준수 정책](../../../docs/marketing/compliance.md)과 [공통 컨텍스트](../../../docs/marketing/context.md)를 이 순서로 확인한다. 기존 자료로 답할 수 없는 중요한 사항만 질문한다.

기존 docs/customer-analytics-measurement-contract.md 및 후속 문서와 실제 구현을 먼저 확인한다. 동일 기간·분모·측정 버전·운영 호스트를 맞추고 누락과 0을 구분한다. KST 완료 기간, 계절성, 표본 크기, 공급자별 정의 및 지연을 기록한다. 전화 클릭은 통화·예약이 아니며 읽기율은 만족도 자체가 아니다. 원시 ID를 내보내지 않는다. 기존 저장 자료와 offline을 우선하고 라이브 조회는 승인 후 수행한다. 추적 코드나 설정은 자동 변경하지 않는다.

- 지표마다 이벤트/세션/사용자 중 집계 단위, 분자·분모, 기간, 대상 호스트, 제외 조건을 표시한다. 전화 클릭 세션율은 같은 범위의 전화 링크 클릭 세션 수 ÷ 전체 대상 세션 수다. 한 세션의 반복 이벤트는 한 번만 세고 분모가 없거나 0이면 계산 불가로 적는다.
- 전후 변화는 절대 차이와 상대 변화(기준값이 있고 0보다 클 때)를 구분한다. 누락·중복·호스트 필터·측정 정의 변경을 우선 확인한 뒤, 가능하면 보유 집계나 합성 이벤트로 분자·분모를 재계산한다.

결과는 [리서치 계약](../../../docs/marketing/research-contract.md)에 맞춰 근거·한계·승인 필요 여부를 기록한다.
