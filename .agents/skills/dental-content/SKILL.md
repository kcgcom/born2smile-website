# 서울본치과 콘텐츠 작업

- [진료 안내](../../../app/treatments), [FAQ](../../../app/faq), [블로그](../../../app/blog)와 제공된 콘텐츠 작업함 자료에서 관련 항목을 확인한다. 해당 URL의 집계나 질문 해결 피드백이 필요하면 [agent:context 사용법](../../../docs/agent-content-workflow.md)을 참고한다.
- 원고의 용어·형식·근거는 [블로그 작성 가이드](../../../docs/blog-writing-guide.md)와 [출처 링크 정책](../../../docs/source-link-policy.md)을 따른다.
- 작업함에 저장하거나 제출하는 요청은 [에이전트 콘텐츠 워크플로우](../../../docs/agent-content-workflow.md)를 따른다. 신규 글의 비공개 초안과 기존 글의 수정안은 별도 경로다. 공개 절차는 [블로그 워크플로우](../../../docs/blog-workflow.md)를 참고한다.
