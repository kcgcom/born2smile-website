# dental-content

루트 및 대상 AGENTS.md를 따른다. 실행 전 [준수 정책](../../../docs/marketing/compliance.md)과 [공통 컨텍스트](../../../docs/marketing/context.md)를 이 순서로 확인한다. 기존 자료로 답할 수 없는 중요한 사항만 질문한다.

기존 글·진료 페이지·작업함을 먼저 확인하고 검색 의도, 환자 질문, 질문 해결 피드백, 임상 최신성 및 중복을 평가한다. 새 글이 추가할 정보가 무엇인지 명시하고 기존 글 보강과 비교한다. 환자 안전·정보 부족·근거 강도·수요·작업 비용으로 우선순위를 정한다. 작성은 blog-writing-guide.md를 따른다. 제안은 대상·근거·완료 기준을 포함하고 승인된 기존 작업 흐름으로만 등록한다. 자동 발행하지 않는다.

- 주제는 환자가 해결하려는 질문과 의사결정 상황별로 묶고 대표 진료·FAQ·블로그 페이지에 연결한다. 같은 검색 의도는 기존 페이지 보강을 우선 검토하고, 별도 글이 필요한 의도라면 대표 페이지와 새 글의 역할 및 내부 연결을 명시한다.
- 편집 계획에는 주제별 질문, 근거와 기준일, 대상 URL 또는 신규 여부, 추가할 범위, 필요한 임상 원문과 의료인 검토, 완료 기준을 넣는다. 질문 빈도만으로 우선순위를 확정하지 않는다.

결과는 [리서치 계약](../../../docs/marketing/research-contract.md)에 맞춰 근거·한계·승인 필요 여부를 기록한다.
